\defmodule{MULT}

This can be either {\tt MULTLI} or {\tt MULTSI}, depending on the chosen
representation.
One can copy one of these two in {\tt MULT} (i.e. copy the
``{\tt .def}'' and the ``{\tt .mod}'' for one of them)
and change the module name (in the code) to {\tt MULT}.
This can also be done automatically using the command {\tt select}.
This module provides tools for manipulating multipliers
before and during the construction of lattice basis
(e.g., checking if the period is maximal, etc.).
