\defmodule{BASIS}

This can be either {\tt BASISLR} or {\tt BASISSI}, depending on the chosen
representation.
One can copy one of these two in {\tt BASIS} (i.e. copy the
``{\tt .def}'' and the ``{\tt .mod}'' for one of them)
and change the module name (in the code) to {\tt BASIS}.
This can also be done automatically using the command {\tt select}.
This module provides tools for manipulating the vectors of a lattice basis
(reduction, etc.) after its construction.
