\defmodule{CONVERT}

This can be either {\tt LILR}, {\tt SILR}, {\tt SISI} or {\tt LISI},
depending the chosen representation.
One can copy one of these four in {\tt CONVERT} (i.e. copy the
``{\tt .def}'' and the ``{\tt .mod}'' for one of them)
and change the module name (in the code) to {\tt CONVERT}.
This can also be done automatically using the command {\tt select}.
